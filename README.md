# 股票交易流程可视化系统

一个轻量级的网页应用，用于动态展示股票订单从创建到结算的全流程。适合教育培训用途。

## 功能特性

### 🎯 核心功能
- **完整的订单生命周期展示** - 13个状态的完整流转
- **多种订单类型支持** - 限价单、市价单、止损单、止损限价单
- **6种预设场景** - 正常买入、立即成交、部分成交、撤单、拒绝、集合竞价
- **交互式控制** - 播放、暂停、单步执行、速度调节
- **多视角展示** - 投资者、券商、交易所、清算所、存管机构

### 📊 可视化功能
- **动态流程图** - 使用Mermaid.js实时渲染当前流程
- **时间线展示** - 按时间顺序显示所有状态变化
- **状态详细信息** - 当前状态的说明和涉及参与者
- **进度统计** - 实时显示完成进度和耗时
- **转换条件说明** - 显示状态转换的规则和条件

### 🎮 交互体验
- **订单创建表单** - 输入股票代码、数量、价格等参数
- **场景选择器** - 快速切换不同交易场景
- **播放控制** - 开始、暂停、单步、重置
- **速度调节** - 0.5x到3x速度可调
- **键盘快捷键** - 空格键播放/暂停，方向键单步执行

## 技术架构

### 前端技术栈
- **HTML5 + CSS3** - 基础页面结构和样式
- **Bootstrap 5** - 响应式布局框架
- **Vanilla JavaScript** - 纯JavaScript实现，无需框架
- **Mermaid.js** - 流程图可视化库
- **CSS Animations** - 动画效果

```
.

│   └── style.css           # 样式文件
```

### 核心模块

#### 1. 状态机模块 (orderFlow.js)
- `OrderStateMachine` - 状态机引擎
- `Order` - 订单实体类
- `Scenario` - 场景定义类
- `ScenarioFactory` - 场景工厂

#### 2. 可视化模块 (visualization.js)
- `VisualizationRenderer` - 可视化渲染器
- 流程图生成和渲染
- 时间线渲染
- 状态信息和转换信息渲染

#### 3. 主控制模块 (main.js)
- `TradingFlowApp` - 应用程序控制器
- 事件处理
- 场景执行
- 状态转换控制

## 使用指南

### 创建订单
1. 输入股票代码（如：000001）
2. 选择订单类型
3. 输入交易量
4. 输入价格（市价单除外）
5. 点击"创建订单"

### 控制演示
- **播放按钮** - 自动执行完整流程
- **暂停按钮** - 暂停自动执行
- **单步按钮** - 手动执行下一步
- **重播按钮** - 重新开始当前场景
- **速度滑块** - 调节演示速度

### 预设场景
- **正常买入** - 限价单完整流程（13步）
- **立即成交** - 市价单快速流程
- **部分成交** - 大订单分批成交演示
- **撤单流程** - 订单撤销演示
- **订单拒绝** - 风控拒绝演示
- **集合竞价** - 开盘集合竞价流程

## 订单状态说明

### 交易前状态
- **待创建** - 订单已创建，等待系统审核
- **已验证** - 通过预交易风控检查
- **路由中** - 正在路由到交易所

### 交易中状态
- **已提交** - 订单已到达交易所
- **排队中** - 在交易所队列中等待
- **交易中** - 订单在交易所订单簿中活跃
- **部分成交** - 订单部分执行

### 完成后状态
- **完全成交** - 订单全部成交
- **待结算** - 进入清算结算流程
- **已结算** - 资金和证券交收完成
- **已撤销** - 订单被撤销
- **已拒绝** - 订单被拒绝
- **已过期** - 订单过期

## 教育方式应用

### 教学建议
1. **概念讲解** - 使用正常买入场景讲解完整流程
2. **对比分析** - 比较不同订单类型的流程差异
3. **异常处理** - 展示撤单、拒绝等异常场景
4. **角色认知** - 通过参与者面板了解各机构职责

### 自学练习
- 尝试不同订单类型
- 观察不同场景下的流程差异
- 使用单步执行理解每个状态转换
- 记录关键状态转换条件

## 自定义配置

### 添加新场景
在 `orderFlow.js` 的 ScenarioFactory 中添加新的场景方法：

```javascript
static createCustomScenario() {
    const scenario = new Scenario('custom', '自定义场景');
    scenario.addStep('pending_new', 'validated', 1000, '验证说明');
    // 添加更多步骤...
    return scenario;
}
```

### 修改状态颜色
在 `orderFlow.js` 的 states 定义中修改 color 字段：

```javascript
validated: {
    name: '已验证',
    description: '订单通过预交易风控检查',
    color: '#17a2b8',  // 修改此颜色值
    nextStates: ['routing', 'rejected']
}
```

### 添加新参与者
在 `orderFlow.js` 的 participants 中添加：

```javascript
this.participants = {
    // ... 现有参与者
    market_maker: {
        name: '做市商',
        description: '提供流动性的交易商'
    }
};
```
